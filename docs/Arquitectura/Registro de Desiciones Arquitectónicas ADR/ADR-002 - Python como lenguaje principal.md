# ADR-002 – Python como Lenguaje Principal

## Estado

Esperando Aprobación

---

## Contexto

El proyecto constituye una plataforma experimental con fuerte orientación a investigación aplicada, análisis de datos y futura integración con tecnologías IoT e Inteligencia Artificial.

---

## Decisión

Utilizar Python como lenguaje principal de implementación.

---

## Justificación

- Amplio ecosistema científico.
- Excelente soporte para IA.
- Integración sencilla con IoT.
- Alta productividad.
- Curva de aprendizaje reducida.
- Amplia adopción académica.

---

## Consecuencias

### Positivas

- Desarrollo rápido.
- Amplia disponibilidad de librerías.
- Excelente soporte para prototipos.

### Negativas

- Menor rendimiento que alternativas compiladas.
- Necesidad de optimizaciones futuras ante altas cargas.

---

## Evolución Futura

La arquitectura permitirá incorporar componentes implementados en otros lenguajes si los requerimientos de rendimiento lo justifican.
